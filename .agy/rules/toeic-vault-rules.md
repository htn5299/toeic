# TOEIC Vault Rules for AI Assistant

When working within this repository:
1. Focus: TOEIC exam preparation (Listening & Reading) and English Grammar in Use.
2. Structure:
   - `English Grammar in Use/`: Theory and exercise workbooks.
   - `Vocabulary/`: Vocabulary notebooks (IPA, definitions, examples, collocations).
   - `TOEIC MOC.md`: Central map of content.
3. Exercise Format:
   - Always use plain empty brackets `[]` (no space inside) as the fill-in placeholder for the user.
   - Include collapsible callouts `> [!success]- 🔑 Đáp án & Giải thích` at the end of each exercise.
4. Note Formatting:
   - Include YAML frontmatter (`title`, `date`, `tags`).
   - Use Obsidian callouts (`> [!abstract]`, `> [!tip]`, `> [!caution]`).
   - Use Mermaid diagrams where appropriate for timelines, workflows, and concept maps.
   - Link notes using Obsidian Wikilinks `[[Note Title]]`.
